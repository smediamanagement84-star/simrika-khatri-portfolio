## 🚀 How to Deploy on GitHub Pages (Step-by-Step)

1. Create a new GitHub repository named `portfolio` (or `simrika-khatri-portfolio`).
2. Upload/push all files from this folder directly to the `main` branch.
3. On GitHub, go to:
   **Repository Settings ➔ Pages ➔ Build and deployment**
4. Under **Branch**, select `main` and folder `/(root)`, then click **Save**.
5. In 1 minute, your portfolio will be live at:
   `https://<your-github-username>.github.io/<repo-name>/`
